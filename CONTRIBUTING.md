# Contributing

1. Fork and create a branch from `main`.
2. Set up: `python -m venv .venv`, activate it, then `pip install -r requirements.txt`.
3. Run locally with `python main.py`; build the EXE with `.\build.ps1`.
4. Open a pull request. CI must pass (it builds the Windows EXE).
